# Evaluation boundaries

Native research and report records remain in the external retirement archive. Metrics shown in the catalog come from exact saved runs and are archival, not new application evaluations. Test labels were not used for tuning or serving selection. Defaults follow existing validation-selected policy.

Current verification exercises real sensor histories, finite values, identity, preprocessing, isolation and parity. ml/registry/verification.json records 168 real CPU routes, including original/tuned models, all seeds, anomaly versus legacy autoencoder RUL and distinct interval methods. Cold-process durations include imports and hashing; they are not a steady-state performance benchmark.

44 primary original/consolidated comparisons passed 1e-8. The legacy historical CSV tolerance failed; exact original/consolidated CPU worst-case execution matched. See TEST_EVIDENCE.md for the unsuppressed discrepancy and evidence files. No GPU performance, N-CMAPSS, diagnostic accuracy, calibrated causal probabilities or text/vision citation-entailment evaluation is claimed.
