# Investigation method and evidence limits

General chat uses the installed local model. Explicit prediction commands must name FD001-FD004 and an engine; the planner resolves the saved validation-selected model and calls it before language interpretation. Photos/industrial scenario data do not trigger C-MAPSS prediction. Structured facility investigations require a scenario, asset and UTC cutoff.

The facility investigator reads the selected asset prefix, then explicit graph neighbors, collecting immutable channel summaries/raw rows and exact event entries. It compares a domain-rule catalogue: lubrication loss, filter restriction, misalignment, cavitation, pressure control, cooling loss, overload, sensor disagreement and deferred service. Catalogue keys deduplicate mechanisms; repeated support IDs count once. This is extensible domain logic, not an exhaustive catalogue of all physical causes or a general semantic hypothesis-merger.

Each hypothesis retains support, contradictions, expected observations, missing measurements, next checks, source version and qualitative status. Ordering is 3 per distinct supporting channel/event, minus 2 per conflict and 0.25 per missing expectation. Two independent supports and score at least 4 receive the label supported; it means rule consistency only. Stable measured lubrication weakens a lubrication explanation; absence alone never rejects it. User notes and model-generated image interpretations cannot become reliable exclusion measurements. A shared dependency is context, not proof. Several supported mechanisms can remain together.

The loop is bounded by config rounds/tool calls/deadline, tracks state hashes/novelty and stops on evidence exhaustion or no progress. Current facility flow expands in two rounds; no unrestricted tool recursion. Completed steps persist even on cancellation/error. Native prediction is a separately isolated CPU process with its own timeout/lock; local LLM calls remain serial. A cancelled synchronous read already in progress may finish, but downstream work stops.

Saved cases preserve evidence snapshots and parent revision IDs. Similarity is canonical mechanism-set overlap, not semantic or calibrated causal similarity. Human notes append separately as unverified local assertions and do not rewrite source facts or force a new conclusion. Reports reproduce stored sources and include their cutoff/limitations. What-if recomputes documented toy assumptions using identical initial seed/noise and withholds future rows past the chosen cutoff.

The evaluator alone reads hidden truth. Its 20-trial engineered benchmark measures rule integration/citation/fencing behavior; it is not independent physics validation, LLM diagnosis accuracy or a real prospective early-warning study. No natural-language unsupported-claim rate or citation-entailment accuracy was measured. See EVALUATION_REPORT.md for actual denominators, per-case lead hours, baseline thresholds and abstentions.
