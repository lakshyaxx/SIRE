# V4.5 hypothesis engine

Generation remains evidence-driven and bounded:0..2concise candidates per proposal round, at most2rounds within220seconds, local document follow-up only. Empty proposals are valid when evidence is insufficient. The engine does not hard-code a fixed final cause count or pad missing candidates.

`identity.merge` now retains every merged candidate; alphabetical slicing at8was removed. Lexical normalization and explicit aliases merge only documented equivalences; general semantic deduplication is not claimed. Duplicate support/conflict relationships remain explicit missing checks. Source-origin grouping prevents repeated copies from counting as independent corroboration.

Every saved investigation has a case lineage key and persistent `CASEHYP` registry records containing canonical identity, definition, actual evaluation, active/deferred selection, rationale and round. An8candidate active budget selects by actual evidence heuristic while deferred definitions remain stored and available to revisions. This is a bounded evaluation budget, not deletion. A12candidate regression retains4deferred definitions and ranks candidates using evidence rather than alphabet order.

Scores are transparent heuristics, not probabilities. Reliable source-declared Boolean predicates may falsify a matching expected sign. Images, confident user claims, unlinked measurements and unknown values cannot independently establish physical rejection. Multiple measurement assets without a selected target are excluded from causal support. Proposal relationships remain tentative unless verified independently.

Historical source fencing applies before generation/retrieval. Revisions preserve previous scope. The previous completed proposal round survives a failed later round as partial. More excerpts from the same existing manual are saved without automatically triggering another expensive proposal round. Expected-sign and follow-up citation aliases are now restored/rejected with the other proposal text.

Actual final generated-photo case retained2tentative low-support alternatives and missing inspections. Its measurements were excluded from causal photo support because physical association was unverified. A false missing-channel claim was corrected by source inventory. These are successful guardrails, not a successful root-cause identification.

Remaining quality defect: the small model can fill schema-bounded mechanism fields with incomplete explanatory phrases. The real final case visibly contains this defect; it is not counted as an engineering-quality semantic pass. Next work should shorten and validate complete mechanism names, preserve originals on any repair attempt, and independently review support/contradiction relationships on approved labeled cases. Learned diagnostic accuracy and calibrated uncertainty are not established by the current tests.
